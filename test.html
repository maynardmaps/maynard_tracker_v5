Route simulation

The selected team drives the chosen route at 60 mph, sending a position report every 10 s. It sends "first turn" (free text) at the first turn, puck message 1, 2 and 3 at the second, third and fourth turns, and an SOS at the end of the route. Uses the Device selected above.

Messaging and tracking control

In Test mode, sending a message and force start/stop tracking are simulated (nothing is sent to Garmin or billed); the tracking state is stored and shown. Use the failure toggle to check error feedback. Events injected above with message types appear in the history.

Fallback test

Clearing stored positions removes all push data, so the map falls back to the MapShare KML feed.

Map icon age filter

In Test mode, temporarily show Garmin and river-level icons older than the configured age limit. This helps check older live KML data; it does not change saved settings or remove location history. The open map tab updates automatically.

Garmin delivery log

Recent requests received at /ipc/outbound, with HTTP response, header names (never values), and request payload. Payloads are size-capped and marked if truncated. Use Garmin's Test button, then refresh.
